# Project Genesis – AI App Builder

An AI-powered application builder that transforms ideas into working applications using Google's Gemini AI.

## Overview

Project Genesis helps users convert their ideas into functional applications by simply describing what they want to build.

## Features

- AI-powered application generation
- Natural language idea input
- Gemini AI integration
- Generated Python application code
- Download generated application
- Interactive Streamlit interface
- Neon-themed user interface

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK

## Installation

1. Clone this repository.
2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Configure your Gemini API key using Streamlit secrets.

4. Run the application:

```bash
streamlit run app.py
```
